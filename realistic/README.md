# 硝子館 — 冬の光景 v0.4

Three.js 0.170.0 を継続使用する、写実表現の試作です。元の `/index.html` と比較できるよう `/realistic/` に追加しています。

## 追加した表現

- 部屋の塊を壁・開口部・床に置き換え、家具、螺旋階段の手すり、細い窓枠、軒の雪を追加。
- 夕景／昼景、生成HDR環境、森を含むキューブマップ反射、物理ベースの材質、実際の落ち影。
- 高精細では透過ガラスとGTAOによる接触部の陰影。Bloomは光源周辺だけに控えめに適用。
- 凹凸のある雪面、119本の針葉樹、遠景の山、入口アプローチ。木はインスタンス化、建物は階・材質ごとに結合。
- 外観／縦断面／水平断面、B1〜11Fの階別表示、部屋名、回転・ピンチ・パン、画像保存。
- ラベルは切断面・画面端・重なりを判定。個別階では天井を外して室内を確認可能。
- 自動画質はタッチ端末で解像度とエフェクトを抑え、軽量設定も用意。非表示タブでは描画を止め、動きを減らす設定を尊重。

## 再現範囲

元の23の空間名と階構成を保持しています。原作図面の厳密な再現ではありません。家具、内装、窓枠、照明、植栽は創作的な補完です。階高は元と同じ3.2、床・外壁・部屋の半径計算を統一し、上層の不正な環状形状を解消しました。

ハードウェアレイトレーシングや動的な多重反射・多重屈折は使用していません。ガラスの反射は代表位置の環境キャプチャで、室内照明の一部は発光材質と補助光による近似です。GTAOは透明物を除外し、断面時は無効化します。

## 検証

- JavaScript構文チェック、esbuildで全importを解決。
- Three.js上で全メッシュを生成し、全頂点・インデックス・境界が有効なことを確認。
- 元の23空間の名前・階の一致、全12階の生成、床表面の法線方向、ラベル位置が外壁内に収まることを確認。
- 建物＋景観：約24.2万三角形、307メッシュ（反復する樹木はインスタンス描画）。
- 検証用Cloud BrowserはWebGLコンテキストを作成できず、元サイトも3Dを描画できなかったため、完成画の目視確認・実機FPS測定は未実施。試作品の実機での操作・画像保存・描画の確認は公開後に必要です。

## 編集

`index.html`：画面構成、`style.css`：レスポンシブUI、`architecture.js`：建物、`landscape.js`：景観、`scene.js`：照明・描画・操作。

ビルド不要でGitHub Pagesに公開できます。開発時はHTTPサーバー経由で開いてください。Three.jsは既存版と同様にjsDelivrから読み込みます。画像テクスチャはコードで生成し、有料素材・有料API・外部レンダリングサーバーは使いません。
